Blocklayouts Preferences
========================

What this screen does
---------------------
The **Blocklayouts Preferences** screen lets you control:

- How the **pattern library** looks and behaves in the editor.
- Which **extra features (extensions)** are turned on or off.

These settings affect your **editing experience** inside WordPress, not the content visitors see directly.

Opening Blocklayouts Preferences
--------------------------------
The exact entry point may vary depending on your setup, but typically you will:

1. Open the block editor (edit any page or post).
2. Look for a **Blocklayouts** button, menu item, or a **Preferences / Settings** icon related to Blocklayouts.
3. Click it to open the **Blocklayouts Preferences** panel or modal.

You’ll usually see at least two tabs:

- **General**
- **Extensions**

General tab
-----------
The **General** tab focuses on how the Blocklayouts pattern library appears.

### Live Preview
- Controls how patterns are displayed in the library:
  - **On** – Patterns are shown as live blocks that you can see in action (more visual, slightly heavier).
  - **Off** – Patterns are shown as static images (faster and lighter, especially on slower machines).

Use live preview if:

- You like to see animations and hover states before inserting patterns.
- You’re on a reasonably fast computer and connection.

Turn it off if:

- The library feels slow or laggy.
- You prefer a simpler, image‑based overview.

### Sorting / Order
- Lets you choose how patterns and templates are sorted in the library.
- Common options include:
  - **Default / Free first**
  - **Newest first**
  - **Oldest first**
  - **By name (A–Z)**

This does not affect your site’s front‑end pages. It only changes how patterns are listed while you browse.

### Items per page
- Sets how many patterns are shown at once in the library grid.
- Examples:
  - 12 items per page (default).
  - 24 or more if you have a large screen and prefer to see more options at once.

If the library feels overwhelming, lower this number; if you prefer scanning many choices quickly, raise it.

Extensions tab
--------------
The **Extensions** tab controls which Blocklayouts enhancements are available.

You’ll see groups like:

- **Enhanced blocks**
- **Additional CSS**
- **Effects**

Each entry has a switch to turn that feature **on or off**.

### Enhanced blocks
- **Button Icon / Inline Icon**
  - When enabled, you can add inline icons inside Button block text.

- **Linked Group / Wrapper Link**
  - When enabled, you can turn Group blocks into full‑card links using the Wrapper Link extension.

### Additional CSS options
These switches control whether you see certain controls in the **Additional CSS** panel:

- **Position**
  - Show or hide the ability to change a block’s position (fixed, sticky, etc.).

- **Transform**
  - Show or hide rotation and movement controls.

- **Background Blur**
  - Enable or disable blur options behind blocks.

- **Opacity**
  - Enable or disable controls for block transparency.

- **Overflow**
  - Let you decide how content that extends beyond a block is handled (shown or hidden).

- **Custom CSS**
  - Shows or hides the text area for writing your own CSS for a block.
  - If your users are non‑technical, you might want this turned off.

### Effects
- **Animations**
  - When enabled, the **Effects** panel appears on eligible blocks so you can add scroll/entrance animations.
  - When disabled, those controls are hidden and blocks will not show additional animation options from this extension.

Why you might turn features off
-------------------------------
You can use Preferences to simplify the editor for non‑technical users:

- Hide features they don’t need (for example, Custom CSS or advanced positioning options).
- Reduce the number of panels in the sidebar.
- Make the editing experience less intimidating for content editors.

You can still turn features back on later if you or another admin needs them.

Best practices
--------------
- Start with **most features on**, then turn off what you know you won’t use.
- If editors feel overwhelmed, hide the more technical tools (especially Custom CSS and some Additional CSS options).
- If the editor feels slow, try:
  - Turning off **Live Preview**, and/or
  - Disabling certain heavy visual extensions you don’t rely on.
