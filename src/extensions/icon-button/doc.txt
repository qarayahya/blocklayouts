The Inline Icon Button extension lets you insert small icons directly inside text, mostly for Button blocks. Add an arrow icon next to "Learn more", a checkmark in front of "Save" or "Confirm", or any other icon that becomes part of the button text, not a separate block. The icon is inline with the text, so it flows naturally and can be positioned before or after the text. This creates more visually interesting and informative buttons without needing to use separate Icon blocks.

How to use it

1. Insert or select a Button block in your editor. The Inline Icon feature works specifically with Button blocks, so make sure you're working with a button, not just any text block.

2. Click inside the button text area so that your cursor is in the text. This will make the text formatting toolbar appear above the button text.

3. Look for the Inline Icon button in that toolbar. It's usually represented by a small icon symbol. The toolbar appears when you're editing text within the button.

4. Click the Inline Icon button to open the icon picker. A small panel or dropdown will appear with icon options.

5. Choose an icon from the quick list of common icons, or click to open the full Icon Library to see more options. The quick list includes commonly used icons like arrows, checkmarks, and other frequently needed symbols. The full library has hundreds of icons organized by category.

6. Once you select an icon, it will be inserted into the button text at your cursor position. You can place it before the text (like "✓ Save"), after the text (like "Learn more →"), or even in the middle if needed.

7. Adjust size and spacing: With the icon selected or the icon picker open, use the controls in the inline icon popover to change the icon size. You can also add space before or after the icon using left/right margin controls. This helps position the icon perfectly relative to the text.

8. Match the button color: There is usually an option to match the icon color to the button's text color automatically. This keeps the appearance consistent when you change button colors later. Turn this on so the icon always matches your button text color.

9. You can add multiple icons if needed, though one icon per button is usually sufficient. Too many icons can make the button feel cluttered.

10. Save your changes and view the button on the front end. The icon should appear inline with the text, flowing naturally as part of the button content.

Settings and options

- Icon selection: Choose from the icon library or quick list of common icons. The library is organized by categories, and you can search for specific icons. Common icons include arrows (for navigation), checkmarks (for confirmation), plus signs (for add actions), and many others.

- Icon size: Control the size of the inline icon, measured in pixels or relative to the text size. The icon should be proportionate to the text—typically slightly smaller or the same size as the text. Icons that are too large will look unbalanced, while icons that are too small may be hard to see.

- Spacing: Add space before or after the icon using left/right margin controls. This helps position the icon relative to the text. For example, you might want a bit more space between an arrow and the text ("Learn more →" vs "Learn more→"). Adjust until it looks balanced.

- Color matching: Option to match the icon color to the button's text color automatically. When enabled, the icon will always use the same color as the button text, so if you change the button text color, the icon color updates automatically. This maintains visual consistency and makes styling easier.

- Icon position: Icons can be placed before the text, after the text, or (in some cases) in specific positions. The position depends on where your cursor is when you insert the icon.

Removing or changing the icon

- To change the icon: Click on the icon in the button text (or place your cursor near it) and open the Inline Icon picker again. Select a different icon to replace it.

- To remove the icon: Use the remove/clear option in the inline icon controls, or simply delete the icon directly from the button text as if it were a character. You can select it and press Delete or Backspace.

Tips

- Use icons to support the text: Choose icons that reinforce the button's purpose. Arrows (→) work well for "Next", "Learn more", or navigation buttons. Checkmarks (✓) are perfect for "Save", "Apply", "Confirm", or success actions. Download icons work for download buttons, external link icons for links to other sites, and so on.

- Don't overdo it: Too many icons inside text can feel cluttered and unprofessional. Keep one icon per button in most cases. If you need multiple visual elements, consider using a separate Icon block instead.

- Keep icon size proportionate to text: Icons that are too large will look unbalanced and dominate the button. Icons that are too small may be hard to see or lose their impact. Aim for icons that are roughly the same size as the text or slightly smaller.

- Make sure the icon color has enough contrast: If the icon matches the text color, it will automatically look good against the button background (assuming your text color already has good contrast). However, if you're using a custom icon color, ensure it has sufficient contrast against the button background for accessibility.

- Position matters: Icons before text (like "→ Learn more") can feel more like navigation. Icons after text (like "Learn more →") are more common and feel like a continuation of the action. Choose based on your design and the button's purpose.

- Test on different button styles: Icons work with all button styles, but they may look different depending on whether the button is outlined, filled, or has other styling. Preview to ensure the icon looks good with your chosen button style.

- Consider the button's purpose: Not every button needs an icon. Use icons when they add value or clarity. Simple actions like "Submit" or "Cancel" might not need icons, while "Download PDF" or "View Portfolio" benefit from visual reinforcement.
