The Typography extension adds extra text-related options to blocks that already support typography. Currently, the main option it exposes is No wrap: when turned on, the text tries to stay on a single line; when turned off, the text can wrap onto multiple lines as usual. This is useful for short labels or badges, menu-like items, and places where you want to avoid awkward line breaks that would look unprofessional or break the design.

How to use it

1. Select a text-based block that supports typography. This includes blocks like Heading, Paragraph, and other blocks that have typography controls. Not all blocks support typography, so if you don't see typography options, this extension won't be available for that block.

2. In the right sidebar, open the Styles tab and then the Typography panel. This is where all text-related styling options are located.

3. Look for an additional Typography or Advanced Typography section within the Typography panel. The extension adds its controls here, separate from the standard typography options like font size and font family.

4. Find the No wrap control. It's typically a toggle switch or checkbox.

5. Turn No wrap on to keep the text on a single line. When enabled, the text will try to stay on one line and won't break into multiple lines, even if it's long. This is useful for short text that should always appear on a single line.

6. Turn it off if the text is too long and looks bad on small screens, or if you want the text to wrap naturally. When disabled, the text will wrap onto multiple lines as needed, which is the default behavior for most text blocks.

7. Preview your changes on different screen sizes, especially mobile, to ensure the text looks good with No wrap enabled.

If a block does not have typography support, this extension will not show for that block. Some simple blocks or blocks without text don't have typography options.

Settings and options

- No wrap: Toggle to keep text on a single line or allow it to wrap naturally. When on, the text tries to stay on one line and won't break into multiple lines. This uses CSS white-space: nowrap. When off, the text can wrap onto multiple lines as usual, which is the default behavior for most text. Use No wrap for short text that should always appear on a single line, like labels, badges, or menu items.

Tips

- Only use No wrap for short text: If the text is long, forcing it onto one line can cause several problems:
  - Horizontal scrolling on smaller screens, which is a poor user experience
  - Text overflowing outside its container, breaking the layout
  - Text becoming too small to read if the container tries to fit it
  - Especially problematic on phones where screen width is limited

- Always check mobile: Preview how your page looks on smaller screens (phones and tablets). If text is cut off, overflowing, or too small with No wrap enabled, consider turning it off or shortening the text. Mobile devices have limited horizontal space, so No wrap can be problematic for longer text.

- Use for badges or labels: A small Heading or Paragraph used as a label on cards or sections benefits from No wrap. For example, "New", "Featured", "Sale", or category labels should stay on one line. Turn No wrap on to avoid the label breaking into two lines, which would look unprofessional.

- Use for short button-like text: A Heading or Paragraph that acts as a compact call-to-action or menu item works well with No wrap. It keeps the text visually tight and on a single line, creating a cleaner appearance. Examples include navigation items, short CTAs, or tab labels.

- Consider text length: As a general rule, if your text is more than 3-4 words, be cautious about using No wrap. Very short text (1-3 words) is usually safe. Medium-length text (4-8 words) might work on desktop but could be problematic on mobile. Long text (8+ words) should almost never use No wrap.

- Test with different content: If the text content might change (for example, user-generated content or dynamic text), be careful with No wrap as future content might be longer than expected.

- Combine with other styling: No wrap works alongside other typography options. You can still adjust font size, weight, and other properties. Sometimes making the font slightly smaller can help text fit on one line, but don't make it so small that it's hard to read.

- Accessibility: Ensure that text with No wrap is still readable. If you need to use No wrap but the text might be long, consider using CSS text-overflow: ellipsis to truncate with "..." if needed, though this requires custom CSS.

- When not to use: Don't use No wrap for body text, long headings, descriptions, or any text that needs to be readable and accessible. It's specifically for short, label-like text that should always appear on one line.
