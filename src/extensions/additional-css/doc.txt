The Additional CSS extension gives you extra visual controls for individual blocks, all in one place. You can nudge blocks around the page, rotate or move them slightly, add a background blur, make them more or less transparent, hide overflowing content, and optionally add your own custom CSS. This is useful when you want more design control than the default block options provide, allowing you to create unique layouts and effects that go beyond standard WordPress block styling.

How to use it

1. Click on the block you want to edit. This can be any block type—Group, Column, Image, Heading, or any other block in your editor.

2. In the right sidebar, go to the Styles tab. This is where all styling options are located.

3. Look for the Additional CSS panel or section. It may be collapsed by default, so click to expand it and see all the available controls.

4. Depending on your Blocklayouts Preferences settings, you may see different sections within Additional CSS. Some features can be turned on or off globally in the preferences, so if you don't see a particular section (for example, Background Blur), it might be disabled there.

5. Each section within Additional CSS has its own controls. Expand the sections you want to use and adjust the settings.

6. Changes are applied immediately in the editor, so you can see the effects as you adjust them.

7. Save your changes and preview on the front end to see how they look in the live site.

Note: Some features can be turned on or off in the Blocklayouts Preferences screen. If you don't see a particular section, it might be disabled there.

Settings and options

- Position: Control how the block sits on the page relative to other elements. Choose normal position (default, follows the normal flow of the page), fixed (stays in the same place even when scrolling), or sticky (stays in place while scrolling until it reaches a certain point). Fine-tune with top, right, bottom, and left offsets to nudge the block in any direction. This is useful for badges that stick to a corner, floating elements, or blocks that need to appear slightly shifted from their normal position. Fixed and sticky positions are powerful but should be used sparingly as they can affect page layout significantly.

- Transform: Rotate or move the block slightly without affecting the layout of other elements. Rotate a block a few degrees for a playful, dynamic design. Shift a block a little to the left/right or up/down to create visual interest. You can combine rotation with translation for more complex effects. Use sparingly; a little movement goes a long way. Too much transform can make a page feel chaotic or unprofessional. Subtle transforms (2-5 degrees rotation, 10-20px translation) often work best.

- Background Blur: Add a soft blur effect to whatever is behind the block, creating a "glass" or frosted-glass effect (also known as glassmorphism). This is achieved using CSS backdrop-filter. Adjust the blur intensity to control how much the background is blurred. This works best when the block has some transparency (opacity less than 1) so you can see the blurred background through it. Good for highlighting a block over a busy background image, creating stylish callout boxes, or modern overlay effects. Note that background blur may not work in all browsers, so test across different browsers.

- Opacity: Control how transparent a block is. The value ranges from 1 (fully visible, completely opaque) to 0 (completely invisible, fully transparent). Use slightly lower opacity (e.g. 0.9 or 0.95) for subtle overlay panels that don't completely block the content behind. Use very low opacity (e.g. 0.1 to 0.3) for decorative elements that shouldn't distract too much. Medium opacity (0.5 to 0.7) works well for modal overlays or emphasis sections. Be careful with text blocks—low opacity can make text hard to read, so ensure there's still good contrast.

- Overflow: Decide what happens when content inside a block sticks out of its container boundaries. Choose "Show everything" (default, content can overflow) or "Hide what doesn't fit" (content is clipped to the block's frame). Hidden overflow is useful for card layouts where images or elements should be neatly cropped to fit within rounded corners or specific dimensions. This is commonly used with border-radius to create perfectly rounded image containers.

- Custom CSS: A text area where you can write your own CSS code for that specific block. This is for advanced users who are comfortable with CSS. You can add any CSS properties here, and they will be scoped to just this block. Use this when the visual controls aren't enough for your specific needs. Keep your CSS focused and well-organized. Only recommended if you (or a designer) are comfortable with CSS, as incorrect CSS can break the block's appearance.

Tips

- Start simple: Try one change at a time (for example, a small blur or tiny rotation) and preview on mobile as well as desktop. Complex combinations of effects can sometimes interact in unexpected ways, so build up gradually.

- Avoid overdoing effects: Too many transforms, blurs, or sticky elements on a single page can make pages feel cluttered, slow, or unprofessional. Use these effects strategically to highlight important content, not on every block.

- Use Custom CSS only if needed: The visual controls are often enough for most design needs. If you use Custom CSS, keep it short and well-focused. Test thoroughly, as custom CSS can sometimes conflict with theme styles or other plugins.

- Test across devices: Effects like transforms and fixed positioning can behave differently on mobile devices. Always preview your changes on different screen sizes.

- Consider performance: Some effects, especially blur and complex transforms, can impact page performance, particularly on lower-end devices. Use them judiciously.

- Accessibility: Be mindful that some effects (like low opacity or blur) can affect readability. Ensure text remains readable and that interactive elements are still clearly identifiable.

- Combine with other styling: Additional CSS works alongside the standard block styling options. You can use both together—for example, set colors and spacing in the standard panels, then add a transform or blur in Additional CSS.
