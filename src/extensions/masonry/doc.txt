The Masonry extension creates a Pinterest-style layout where items of different heights fit together like a puzzle. Instead of rigid rows where short items leave empty space below them, masonry lets items flow naturally at different heights, fills gaps intelligently so content looks balanced, and creates a dynamic, magazine-like look. This works with Group blocks (when set to grid layout) and Gallery blocks, making it perfect for image galleries, blog post grids, portfolios, and any content where items have varying heights.

How to use it

1. Add a Group block to your page and set its layout to Grid. Alternatively, you can use a Gallery block, which already has a grid structure. The masonry effect requires a grid layout to work.

2. Add several blocks inside the Group or Gallery. These can be images, paragraphs, cards, or any combination of blocks. The key is that they should have varying heights—masonry works best when items are different sizes. For example, mix tall images with short text blocks, or cards with different amounts of content.

3. Configure your columns: For Group blocks, set your grid columns using one of two methods:
   - Column count: Set a fixed number of columns (e.g. 3 columns). This works well when you know exactly how many columns you want.
   - Minimum column width: Set a minimum width (e.g. 12rem or 300px), and columns will adjust automatically to fit the screen. This is more flexible and responsive.

4. For Gallery blocks, use the existing Columns setting in the block settings. The masonry will respect this column count.

5. Adjust spacing (optional): In the Styles panel, set Block spacing to control the gap between items in the masonry layout. This spacing will be consistent across all items. More spacing creates a cleaner, more separated look. Less spacing creates a tighter, more compact grid.

6. Select the Group or Gallery block and scroll down in the right sidebar to find the Advanced panel. This is where extension settings are typically located.

7. Look for the Masonry toggle within the Advanced panel. It may be a simple on/off switch.

8. Turn on the Masonry toggle to enable the masonry layout.

9. Save your changes and view the page on the front end. The masonry effect only appears on the live site, not in the editor. In the editor, you'll see your regular grid layout (this makes editing easier), but on the front end, items will rearrange to fill vertical space efficiently.

Note: The masonry effect only appears on the front end of your site, not in the editor. The editor shows your regular grid to make editing easier, but when you view the live page, items will be arranged in the masonry layout.

Settings and options

- Masonry toggle: Enable or disable the masonry layout in the Advanced panel. When enabled, items will flow to fill gaps. When disabled, you'll have a standard grid layout.

- Column count: For Group blocks, set the number of columns for a fixed grid (e.g. 3 columns). This works well for consistent layouts where you want the same number of columns on all screen sizes (though you may need to adjust for mobile).

- Minimum column width: For Group blocks, let columns adjust automatically to fit the screen by setting a minimum width (e.g. 12rem or 300px). The browser will calculate how many columns fit based on the available space. This is more flexible and responsive than a fixed column count.

- Block spacing: Control the gap between items in the masonry layout. This is set in the Styles panel under spacing options. More spacing (20-40px) creates breathing room. Less spacing (10-20px) creates a tighter grid. The spacing should be consistent with your overall design.

Tips

- Use 3–4 columns for a balanced look: Too many columns (5+) makes items feel cramped and hard to see. Too few columns (1-2) can make gaps more obvious and doesn't take full advantage of masonry. Three or four columns is usually the sweet spot for most content.

- Vary content heights naturally: Masonry works best when you have a mix of short and tall items. If all items are the same height, regular grid is fine and you don't need masonry. Create variety by mixing images of different aspect ratios, text blocks of different lengths, or cards with varying amounts of content.

- Keep spacing consistent: Use the same block spacing across your masonry grids for a professional, cohesive feel. Inconsistent spacing can make the layout feel chaotic.

- Test on different screen sizes: Masonry adapts to your responsive grid settings. Preview on mobile, tablet, and desktop to ensure the layout looks good at all sizes. On mobile, you might want fewer columns (1-2), while desktop can handle more (3-4).

- Use minimum column width for flexibility: Instead of a fixed column count, use minimum column width to let columns adjust automatically. This keeps your layout looking good on all devices without needing separate settings for each screen size.

- Pair with the Gallery block: The core Gallery block already supports columns and is perfect for masonry photo layouts. Simply enable masonry in the Advanced panel, and your gallery images will flow naturally.

- Consider your content: Masonry is ideal for image galleries, blog post cards, portfolio items, testimonials, or any content where items have natural height variation. It's less useful for uniform content like a grid of identical product images.

- Performance: Masonry uses JavaScript to calculate positions, so very large grids (50+ items) might take a moment to arrange. This is usually not noticeable, but be aware if you're creating very large grids.

- Editing: Remember that the editor shows a regular grid for easier editing. Don't worry if items look different in the editor—the masonry layout only appears on the front end. This makes it easier to add, remove, and rearrange items.
