The Marquee block creates a horizontally scrolling strip of content. Anything you place inside the Marquee (icons, text, logos, buttons, etc.) will move continuously across the screen, similar to a news ticker or logo carousel. The content scrolls smoothly in a continuous loop, creating an eye-catching animated section. Great for scrolling brand or client logos, short promotional messages, highlighted features or offers, and creating dynamic, engaging sections that draw attention.

How to add this block

1. Open the editor and navigate to the page or template where you want to add a marquee.

2. Click the + button (Add block) in the editor toolbar or within an existing block.

3. Search for "Marquee" in the block inserter and click to insert it.

4. Once inserted, you'll see an empty Marquee block with a placeholder area. The block acts as a container for other blocks.

5. With the Marquee block selected, click the + button inside it to add content. You can add various types of blocks:

   - Image blocks: Perfect for logos, brand marks, or product images. Add multiple Image blocks in a row to create a logo carousel.

   - Heading blocks: Use for short promotional messages or announcements. Keep text brief since it will be scrolling.

   - Paragraph blocks: Add short descriptions or taglines that scroll by.

   - Button blocks: Create scrolling call-to-action buttons, though these work best when the marquee pauses on hover.

   - Icon blocks: Add icons that scroll along with other content.

6. You can add one block and duplicate it multiple times to create repetition, or add multiple different blocks in a row for variety. For logo carousels, duplicate the same Image block several times so the logos repeat seamlessly.

7. Arrange the blocks in the order you want them to appear in the scroll. The first block will be the first to appear.

How to style it

Use the style panels in the sidebar to match the Marquee to your site:

- Color: Set a background color for the entire marquee strip (e.g. a light band running across the page, or a dark section for contrast). This creates a distinct area that separates the marquee from the rest of the page. Adjust text color for any text inside the Marquee to ensure good contrast against the background. You can also set link colors if your marquee contains linked content.

- Border: Add a border around the entire marquee to create a frame. Add rounded corners (border radius) to create a pill-style banner or soft, modern look. Adjust border color and width to match your design. A subtle border can help define the marquee area without being too prominent.

- Spacing: Add padding inside the Marquee so content doesn't touch the edges. Vertical padding (top and bottom) is especially important to prevent content from feeling cramped. Adjust margins above and below the Marquee to separate it from other sections. More margin creates more visual separation and breathing room.

- Typography: If your marquee contains text, you can adjust font size, weight, and style. Larger text is easier to read as it scrolls, but don't make it so large that it dominates the page.

Settings and options

- Direction: Choose whether the content moves from right to left (common for logo strips and most Western reading patterns) or from left to right (less common, but can create visual interest). Right to left is the default and feels most natural for most users.

- Speed: Use the slider to adjust how fast the content moves across the screen. Slower speeds (lower values) are easier to read and less distracting, making them better for text content. Faster speeds (higher values) are more eye-catching and dynamic, but can be harder to read and may feel overwhelming. Start with a moderate speed and adjust based on your content type and user feedback.

- Gap between items: Adjust the Gap between items (px) slider to control the horizontal space between each logo, image, or block. Higher values give more breathing room between items, making the marquee feel less crowded. Lower values create a tighter, more compact look. For logos, a moderate gap (around 40-60px) usually works well. For text, you might want more space.

- Pause on Hover: Turn this on if you want the marquee to stop moving when a visitor hovers their mouse over it. This is essential when: you want users to have time to read text content, items inside the marquee are clickable (like linked logos), or you want to reduce motion for accessibility. When paused, users can interact with the content more easily. This is highly recommended for marquees with interactive elements.

Tips

- Keep text short and simple so visitors can quickly understand messages as they scroll by. Long sentences or paragraphs won't work well in a marquee. Aim for headlines, taglines, or very brief announcements.

- Don't stack too many moving sections on a single page; too much animation can feel overwhelming and distracting. One marquee per page is usually enough. If you need multiple scrolling sections, consider placing them far apart on the page.

- Make sure important information also appears in a non-moving section somewhere, in case visitors find motion difficult to follow or have motion sensitivity. Never put critical information only in a marquee.

- For logo carousels, use high-quality images that are all roughly the same size. This creates a more professional, polished look. Consider using a light or dark background to make logos stand out.

- Test the marquee on different screen sizes. On mobile devices, the scrolling might feel different, and you may need to adjust the speed or gap settings.

- Consider your audience: Some users may find continuous motion distracting or uncomfortable. The "Pause on Hover" option helps, but be mindful of accessibility concerns.

- For promotional messages, combine the marquee with other static content to create a balanced page. The marquee should enhance, not dominate, the page design.
